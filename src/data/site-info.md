# À propos de Not So Informatic

**Not So Informatic** est un mélange de plusieurs projets informatiques.  
Avec les cours de _Numérique et Sciences Informatiques_ et mes autres projets perso de mes deux années de lycée.  
Ce repo sert à garder une _trace_ de l'**évolution de mon expérience** dans le `dev`.  
Si vous tombez sur ce site par hasard, je vous conseille vivement de consulter le [repo](https://github.com/mokotanin/not-so-informatic) lui-même.

## Comment naviguer ?

Naviguez au feeling, comme vous le sentez. Le repo est assez structuré donc ce ne devrait pas être compliqué.

### Raccourcis

- `/` ou `Ctrl+K` ( `⌘K` sur Mac) : ouvrir la recherche.
- `↑` et `↓` : parcourir les résultats.
- `Entrée` : ouvrir le résultat sélectionné.
- `Échap` : fermer la recherche ou cette fenêtre.
