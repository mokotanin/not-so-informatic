## autorun for amw

simple gui app to make both apps work in harmony
apple music RP would start when the app opens and close when the app is quitted

## installation

1. clone the repository
2. create a virtual environnment inside of the yokiku folder (not amp_autostart)
3. install dependencies

```
pip install pywinstyles sv-ttk psutil
```

4. run `app.py`
